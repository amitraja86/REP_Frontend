# Clone the project url from github
# Open project folder and run this command to install react scripts
  -> npm install react-scripts
# Also install following things for this project 
  -> chart.js - npm install chart.js
  -> file-saver - npm install file-saver
  -> react-icons - npm install react-icons 
  -> sweetalert2 - npm install sweetalert2

# Install versions of these dependecies compatible to these versions below  

# Versions ::::
* Node.js - v22.14.0
* Npm - 10.9.2
* React - 19.0.0

# To start the react app use command :
  -> npm start
  this will start the server and redirect to the browser with local url ("(http://localhost:3000)")
